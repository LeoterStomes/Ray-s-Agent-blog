## 博客功能速览

| 功能 | 入口 |
|------|------|
| 首页 | 导航栏「首页」— 文章/统计/标签云/音乐 |
| 文章 | 导航栏「文章」— 分类筛选 + 全局搜索(Ctrl+K) |
| 文章详情 | 深色主题，左目录右推荐，底部评论区 |
| 项目 | 导航栏「项目」— GitHub 项目展示 |
| 编辑器 | 头像菜单→「上传博文」 |
| 管理后台 | 导航栏「管理」(仅站长) |
| AI 浮窗 | 右下角按钮 → 全屏点右上角展开 |
| 深色模式 | 右下角月亮图标 |
| 收藏 | 文章详情心形按钮 |

**遇到这类问题时直接回答，不要调工具搜索。**
